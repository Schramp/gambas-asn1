# Installing gambas-asn1

gambas-asn1 is a compiler (`asn1cpp`) plus one runtime library for each
target language. Generated code and its runtime belong together: code
generated by one compiler commit uses that commit's runtime API. Build both
from the same checkout and reinstall the runtime after you update it.

## 1. Build the compiler

Needs CMake ≥ 3.20, GCC or Clang with C++20, Bison ≥ 3.8 and RE/flex 6.1.0.
How to install those is in [doc/QUICKSTART.md](doc/QUICKSTART.md#dependencies).

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel $(nproc)
```

The compiler is `build/compiler/asn1cpp`. There is no `make install`. Run it
from the build tree, or copy it or link to it from a directory on your `PATH`:

```bash
ln -s "$PWD/build/compiler/asn1cpp" ~/.local/bin/asn1cpp
```

The C++ runtime is built along with it (`build/runtime/libasn1cpp_runtime.a`,
headers in `runtime/include`). The Rust runtime is the crate in
`rust-runtime/wire`; use it as a path dependency.

## 2. Install the Java runtime into the local Maven repository

Needs JDK 21. The Gradle wrapper is checked in, so you do not need to install
Gradle.

```bash
./java-runtime/gradlew -p java-runtime publishToMavenLocal
```

This installs `io.github.schramp.gambasasn1:gambasasn1-wire:0.1.0-SNAPSHOT`
into `~/.m2/repository/io/github/schramp/gambasasn1/gambasasn1-wire/`: the jar,
its POM and Gradle module file, and the `-sources` and `-javadoc` jars. No
signing key is needed for a local install. Options:

- `-Pversion=X.Y.Z` installs under another version.
- `-Dmaven.repo.local=<dir>` installs into another local repository instead of
  `~/.m2/repository`.

Run the command again after pulling a newer compiler, so that the runtime in
`~/.m2` matches the code you generate.

### Maven

```xml
<dependency>
  <groupId>io.github.schramp.gambasasn1</groupId>
  <artifactId>gambasasn1-wire</artifactId>
  <version>0.1.0-SNAPSHOT</version>
</dependency>
```

Maven looks in `~/.m2/repository` first, so this needs no extra repository
entry.

### Gradle (Kotlin DSL)

```kotlin
repositories {
    mavenLocal()
    mavenCentral()
}

dependencies {
    implementation("io.github.schramp.gambasasn1:gambasasn1-wire:0.1.0-SNAPSHOT")
}
```

## 3. Generate code and build against the runtime

```bash
asn1cpp --target=java --package=contacts contact.asn1 -o src/main/java/contacts
```

The generated sources need nothing but `gambasasn1-wire` on the class path.
`examples/contact-book/maven/` is a complete Maven project that does all of
this. `make test` there installs the runtime into a private repository
(`m2/`), generates the classes, compiles them with Maven and checks the
output.

## Uninstalling

```bash
rm -rf ~/.m2/repository/io/github/schramp/gambasasn1
```
